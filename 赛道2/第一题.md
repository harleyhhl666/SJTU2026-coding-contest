# T836149 26fa 2-1守包落位

## 题目背景

在 CS2 中，T 阵营成功在 A 区埋下炸弹后，最关键的阶段便是守包（Post-Plant）。Mirage 的 A 区地形复杂，由多个点位通过狭窄的通道相连。T 方的教练正在开发一款战术分析工具，用于实时评估各个点位的防守价值，以便指挥队员进行最优站位。

## 题目描述

A 区及其周边区域可以抽象为一棵包含 $n$ 个节点的树，节点编号为 $1$ 到 $n$。节点 $1$ 为炸弹安放点（默认下包位）。

每个点位有一个**防守值** $v_i$，表示该点位在守包时的战略价值（可为负数，表示该点位容易被 CT 反清，价值为负）。

接下来会发生 $q$ 个事件，事件分为以下三种：

- `1 u x`：点位 $u$ 的防守值变为 $x$（队员 reposition 或受到伤害/击杀人头导致局势变化）。
- `2 u`：查询以点位 $u$ 为根的子树中，所有点位防守值之和。
- `3 u`：查询以点位 $u$ 为根的子树中，所有点位防守值的最大值。

树以节点 $1$ 为根。输入给出每个点位的初始防守值以及与其直接通过通道相连的所有相邻点位编号，但**不给出相邻点位的数量**。

## 输入格式

第一行包含两个整数 $n, q$，表示节点数和事件数。

接下来 $n$ 行，第 $i$ 行描述编号为 $i$ 的点位。

每行第一个整数 $v_i$ 表示该点位的初始防守值。随后给出若干个整数，表示与该点位直接相连的所有相邻点位编号。这些编号的顺序任意，行内不单独给出相邻点位的数量。

接下来 $q$ 行，每行描述一个事件，格式如上所述。

## 输出格式

对于每个类型为 $2$ 或 $3$ 的事件，输出一行一个整数，表示对应的答案。

## 输入输出样例 #1

### 输入 #1

```
5 5
10 2 3
20 1 4
-5 1
15 2 5
8 4
2 1
3 2
1 2 -10
2 1
3 2
```

### 输出 #1

```
48
20
18
15
```

## 说明/提示

树的结构为：1-2-4-5 以及 1-3。

- 初始时，查询子树 $1$ 的和：$10+20+(-5)+15+8=48$。
- 查询子树 $2$ 的最大值：$\max(20, 15, 8)=20$。
- 修改点位 $2$ 的值为 $-10$。
- 再次查询子树 $1$ 的和：$10+(-10)+(-5)+15+8=18$。
- 查询子树 $2$ 的最大值：$\max(-10, 15, 8)=15$。

| 测试点 | $n$ | $q$ | 特殊性质 |
| :---: | :---: | :---: | :---: |
| $1\sim4$ | $\leq 100$ | $\leq 100$ | — |
| $5\sim8$ | $\leq 5000$ | $\leq 5000$ | 只有类型 $2$ 的查询 |
| $9\sim12$ | $\leq 10^5$ | $\leq 10^5$ | 只有类型 $2$ 的查询 |
| $13\sim16$ | $\leq 10^5$ | $\leq 10^5$ | 只有类型 $3$ 的查询 |
| $17\sim20$ | $\leq 10^5$ | $\leq 10^5$ | — |

对所有测试点保证 $1 \leq n, q \leq 10^5$，$|v_i|, |x| \leq 10^9$。
