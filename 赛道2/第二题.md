# T836206 26fa 2-2陈光之序

## 题目背景

小沉听说最近有一个推箱子的游戏很火，也想试着推一推箱子。不过，比起把箱子推到指定位置，他更想搭出一点不一样的东西。

于是，小星找来了许多大小相同的正方体箱体，把它们整整齐齐地堆成了一个大立方体。到了晚上，小之发现其中有些特殊箱体竟然会发光，光还能透过其他箱体，形成不同的光影效果。

小序给普通箱体分别设定了观赏值，想知道这些特殊箱体朝不同方向发光时，整个立方体的观赏值最低和最高分别是多少。

## 题目描述

堆成的大立方体由 $a^3$ 个 $1\times1\times1$ 的箱体组成，编号为 $1$ 到 $a^3$。输入给出每个箱体的观赏值及与其有共同面的箱体编号，箱体编号与空间位置没有固定对应关系。

其中有 $n$ 个特殊箱体会发光，其余箱体为普通箱体。每个发光箱体各自独立地、等概率地从上、下、左、右、前、后六个方向中选择一个方向，沿该方向发出穿透光。光会照亮该方向上的所有箱体，直到离开立方体，且不会被其他箱体阻挡。

立方体的观赏值是所有被照亮的普通箱体的观赏值之和。同一个箱体即使被多束光照亮，也只计算一次。

请你求出立方体观赏值的最小值和最大值。

## 输入格式

第一行包含一个整数 $a$，表示大立方体的边长。

接下来 $a^3$ 行，第 $i$ 行描述编号为 $i$ 的箱体，每行包含若干整数。

每行第一个整数 $g_i$ 表示这个箱体的观赏值。若 $g_i=0$，则这个箱体会发光；否则，这个箱体为不会发光的普通箱体。

随后给出 $3\sim6$ 个整数，表示与这个箱体有共同面的箱体编号。这些编号的顺序任意，行内不单独给出相邻箱体的数量。

## 输出格式

输出一行，包含两个整数，分别表示大立方体观赏值的最小值和最大值，中间用一个空格分隔。

## 说明/提示

### 样例 #1 解释

编号为 $1$ 和 $2$ 的箱体会发光。

- 两个发光箱体均选择朝立方体外部发光时，不会照亮任何非发光箱体，观赏值为 $0$。
- 编号为 $1$ 的箱体选择照向编号为 $3$ 的箱体，编号为 $2$ 的箱体选择照向编号为 $4$ 的箱体时，观赏值为 $4+8=12$。

由于立方体边长为 $2$，每束光最多照亮一个非发光箱体。以上两种情况分别达到最小值和最大值。

### 样例 #2 解释

八个箱体全部发光，没有非发光箱体，因此无论选择什么方向，观赏值均为 $0$。

### 样例 #3 解释

唯一的光源在立方体中心。其余箱体的观赏值均为 $1$，任意方向都恰好照亮一个箱体，因此最小值和最大值均为 $1$。

### 数据规模和约定

每个测试点 $5$ 分，共 $20$ 个测试点，满分 $100$ 分。

::cute-table{tuack}
| 测试点 | $a$ | 发光箱体数量 $n$ |
| :---: | :---: | :---: |
| $1\sim4$ | $\leq 5$ | $\leq 3$ |
| $5\sim8$ | $\leq 20$ | $\leq 5$ |
| $9\sim12$ | $\leq 70$ | $\leq 2$ |
| $13\sim15$ | $\leq 70$ | $\leq 6$ |
| $16\sim20$ | $\leq 70$ | $\leq 8$ |

对于全部测试点，保证 $2\leq a\leq70$，$0\leq g_i<10^6$，$1\leq n\leq8$。其中 $n$ 为满足 $g_i=0$ 的箱体数量，不在输入中单独给出。
