# SJTU 2026 编程周赛

上海交通大学 2026 秋季学期（26fa）编程周赛的题解代码、题面与测试脚本。

## 目录结构

```
.

│   ├── 题目.md          # 三道题的题面（含样例）
│   └── sol/
│       ├── t1.cpp       # 1-1 物资分配（T836214）：0/1 背包
│       ├── t2.cpp       # 1-2 整除问题（T836895）：r 进制整除 / 模逆元
│       ├── t3.cpp       # 1-3 套包（T836868）：离散值分段 + 贪心
│       └── test.py      # 样例 + 暴力对拍 + 极限数据
└── 赛道2/
    ├── 第一题.md / 第二题.md / 第三题.md
    └── sol/
        ├── t1.cpp       # 2-1 守包落位（T836149）：DFS 序 + 线段树
        ├── t2.cpp       # 2-2 陈光之序（T836206）：网格图还原坐标 + 方向枚举
        ├── t3.cpp       # 2-3 连段练习（T836182）：最小覆盖子串 + 记忆化
        └── test.py      # 样例 + 暴力对拍 + 极限数据
```

## 题目与思路

| 题号 | 题目 | 核心思路 |
|---|---|---|
| 1-1 | 物资分配 | 0/1 背包，倒序枚举容量，`long long`，O(nC) |
| 1-2 | 整除问题 | Horner 法求 N mod m；系数 k 取 r 在模 m 下的逆元；序列用“删末位 + 加 k·d”迭代 |
| 1-3 | 套包 | 只看不同规格值，按极长连续段，每段最多取 ⌈len/2⌉ 个 |
| 2-1 | 守包落位 | 按行解析邻接表，迭代 DFS 序，线段树维护区间和/最大值，单点修改 |
| 2-2 | 陈光之序 | 由邻接关系用曼哈顿距离还原三维坐标，再求最小/最大观赏值 |
| 2-3 | 连段练习 | 双指针滑动窗口求最小覆盖片段，对 (l,r) 记忆化 |

各文件头部注释有更详细的推导。

## 编译与测试

需要 g++（支持 `bits/stdc++.h`）与 Python 3。

```bash
cd 赛道1/sol    # 或 赛道2/sol
g++ -O2 -std=c++17 t1.cpp -o t1
g++ -O2 -std=c++17 t2.cpp -o t2
g++ -O2 -std=c++17 t3.cpp -o t3
python3 test.py
```

`test.py` 会从题面 `.md` 中解析样例，并与暴力解法随机对拍，同时跑极限数据检查耗时。
可执行文件需放在 `sol/` 目录下，Windows 上请按脚本中的文件名（如 `t1.exe`）确认。
