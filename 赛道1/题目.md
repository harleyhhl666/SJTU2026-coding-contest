# T836214 26fa 1-1物资分配

## 题目背景

毒圈已经缩小到最后一个安全区，你蹲在残墙后面，面前是刚落地不久的空投箱。物资很多，但背包就这么大，你必须决定把哪些东西塞进去。在决赛圈里，取舍比枪法更决定成败。

## 题目描述

你的背包最多能承载 $C$ 单位的重量。地上共有 $n$ 件物资，第 $i$ 件物资的重量为 $w_i$，能带来的战力提升为 $v_i$。每件物资最多只能拿一件。

请求出：在背包总重量不超过 $C$ 的前提下，所能获得的最大战力提升总和。

## 输入格式

第一行包含两个整数 $n, C$，分别表示物资数量和背包容量上限。

接下来 $n$ 行，每行包含两个整数 $w_i, v_i$，分别表示第 $i$ 件物资的重量和战力提升。

## 输出格式

输出一行一个整数，表示能获得的最大战力提升总和。

## 输入输出样例 #1

### 输入 #1

```
3 10
5 6
4 7
6 10
```

### 输出 #1

```
17
```

## 输入输出样例 #2

### 输入 #2

```
4 6
5 10
3 4
3 5
1 1
```

### 输出 #2

```
11
```

## 输入输出样例 #3

### 输入 #3

```
4 5
2 6
2 6
1 0
5 11
```

### 输出 #3

```
12
```

## 说明/提示

**样例 #1**：

- 选 $(5,6)$ 与 $(6,10)$，总重量 $11>10$，超重。
- 选 $(4,7)$ 与 $(6,10)$，总重量 $10\le 10$，总战力 $7+10=17$。

故最大值为 $17$。

**样例 #2**：

- 选 $(5,10)$ 与 $(1,1)$，总重量 $6\le 6$，总战力 $11$。
- 选 $(3,4)$ 与 $(3,5)$，总重量 $6\le 6$，总战力 $9$。
- 选 $(5,10)$ 与 $(3,5)$，总重量 $8>6$，超重。

故最大值为 $11$。

**样例 #3：**

选择前两件物品，总体积为 $4$，总价值为 $12$；也可以再选择价值为 $0$ 的第三件物品。两件相同的物品可以分别选择。

## 数据规模和约定

共 $20$ 个测试点，每个测试点 $5$ 分。表中各行独立描述对应测试点的约束。

::cute-table{tuack}
| 测试点编号 | $n$ | $m$ | 附加约束 |
| :---: | :---: | :---: | :---: |
| $1$—$3$ | $1\le n\le20$ | $1\le m\le20$ | $0\le v_i\le1000$ |
| $4$—$7$ | $1\le n\le1000$ | $1\le m\le1000$ | $w_i=1$ |
| $8$ | $1\le n\le1000$ | $1\le m\le1000$ | $0\le v_i\le100$ |
| $9$—$13$ | $1\le n\le1000$ | $1\le m\le1000$ | $1\le w_i\le10$ |
| $14$—$20$ | $1\le n\le1000$ | $1\le m\le1000$ | 无 |

对于全部测试点，$1\le n\le1000$，$1\le m\le1000$，$1\le w_i\le1000$，$0\le v_i\le10^9$，所有输入均为整数。物品体积允许超过背包容量。各参数的公共最大值允许同时取到。

# T836895 26fa 1-2整除问题

## 题目背景

判断一个数能否被某个整数整除时，有时可以使用“末位乘系数法”：去掉末位，再加上末位数字与某个系数的乘积。这个方法也可以用于其他进制。

## 题目描述

给定进制 $r$、除数 $m$，保证 $\gcd(r,m)=1$。另给出两个以 $r$ 进制表示的非负整数：初始数 $N$ 和待查找的目标数 $T$。

对当前数 $x$，将它的 $r$ 进制表示从最后一位前面拆开：前面的所有数字组成前缀数 $q$，最后一位的数值记为 $d$。

具体地，若去掉多余前导零后的表示有 $\ell$ 位，且 $\ell\ge2$，则拆分过程为：

$$
x=(\underbrace{a_{\ell-1}a_{\ell-2}\cdots a_1}_{\text{前缀数 }q}\ \underbrace{a_0}_{\text{末位数字 }d})_r,
\qquad x=rq+d.
$$

这里每个 $a_i$ 表示一位数字，$d=a_0$，且 $0\le d<r$。例如，在十进制下，$203$ 拆成前缀数 $q=20$ 和末位数字 $d=3$，因此 $203=10\times20+3$。若 $x$ 只有一位，则前缀为空，规定 $q=0$；零也按一位数处理。

容易证明，存在一个整数系数 $k$，使得对任意非负整数 $x$，$x$ 能被 $m$ 整除，当且仅当拆分后得到的 $q+kd$ 能被 $m$ 整除。本题取满足 $0\le k<m$ 的系数 $k$，在此范围内这样的 $k$ 唯一。当 $m=1$ 时，规定 $k=0$。

选定 $k$ 后，每一步都按上述方式拆分当前数，再将它替换为：

$$
F(x)=q+kd.
$$

所有运算均为普通整数运算，变换后不对 $m$ 取模。特别地，$F(0)=0$。

从 $x_0=N$ 开始，不断令 $x_{i+1}=F(x_i)$，直到首次出现与此前某项相等的数。请完成以下任务：

1. 判断原数 $N$ 能否被 $m$ 整除。
2. 输出系数 $k$，以十进制表示。
3. 判断 $T$ 是否在上述序列中出现过，初始项 $N$ 也算出现。

比较两个数时按数值比较，忽略前导零。

## 输入格式

第一行包含两个以十进制表示的正整数 $r,m$。

第二行包含字符串 $N$，第三行包含字符串 $T$。它们均为合法的 $r$ 进制非负整数表示，允许前导零。

数字字符依次为 `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`，其中 `A` 到 `Z` 分别表示 $10$ 到 $35$；只允许使用数值小于 $r$ 的字符，不使用小写字母、正负号或进制前缀。

## 输出格式

输出三行：

第一行：若 $m\mid N$，输出 `Yes`，否则输出 `No`。

第二行：输出十进制整数 $k$。

第三行：若 $T$ 出现过，输出 `Yes`，否则输出 `No`。

## 输入输出样例 #1

### 输入 #1

```
10 7
203
28
```

### 输出 #1

```
Yes
5
Yes
```

## 输入输出样例 #2

### 输入 #2

```
2 3
101
0
```

### 输出 #2

```
No
2
No
```

## 输入输出样例 #3

### 输入 #3

```
16 1
A0
A
```

### 输出 #3

```
Yes
0
Yes
```

## 说明/提示

系数 $k$ 固定为上述范围内的取值，不能替换为其他同余的整数。零能被任意正整数整除。


## 样例解释

样例 1：序列为 $203,35,28,42,14,21,7,35$，最后一项首次重复，$28$ 出现过。

样例 2：为方便阅读，以下数值均用十进制表示。$(101)_2=5$，不能被 $3$ 整除；系数为 $2$。序列为 $5,4,2,1,2$，零没有出现。

样例 3：所有整数都能被 $1$ 整除，规定 $k=0$。以十六进制表示的序列为 `A0`、`A`、`0`、`0`，因此目标 `A` 出现过。

## 数据规模和约定

设 $L_N$、$L_T$ 分别为输入字符串 $N$、$T$ 的长度，长度包含前导零。共 $20$ 个测试点，每点 $5$ 分。

::cute-table{tuack}
| 测试点编号 | $L_N,L_T$ 上限 | $m$ 上限 |
|:---:|:---:|:---:|
| $1\sim4$ | $5$ | $35$ |
| $5\sim8$ | $100$ | $100$ |
| $9\sim12$ | $500$ | $2000$ |
| $13\sim16$ | $3000$ | $2000$ |
| $17\sim20$ | $3000$ | $20000$ |

对于全部测试点，$2\le r\le36$，$1\le m\le20000$，$\gcd(r,m)=1$，$1\le L_N,L_T\le3000$；$N$、$T$ 均为使用上述大写数字字符的合法非负整数表示，允许前导零。

# T836868 26fa 1-3套包

## 题目背景

在《暗区突围》中，干员会通过套包来整理和携带物资。撤离前，背包可以装入另一个更大的背包，以便进一步收纳。本题用一个整数表示背包的规格，并采用下述套包规则。

## 题目描述

一个背包有一个规格值。若外层背包 $x$ 的规格值为 $a_x$，内层背包 $y$ 的规格值为 $a_y$，当且仅当

$$
a_y-a_x\ge 2
$$

时，内层背包 $y$ 可以套入外层背包 $x$。背包可以多层嵌套。

接下来进行 $n$ 次搜集，第 $i$ 次获得一个规格值为 $a_i$ 的背包。对于每个 $i$，请计算获得前 $i$ 个背包后，最多能连续套包多少层。每个背包在一条嵌套链中至多使用一次。

## 输入格式

第一行包含一个正整数 $n$。

第二行包含 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一行 $n$ 个正整数。第 $i$ 个数表示只使用前 $i$ 个背包时，最多能连续套包的层数。相邻整数之间以空格分隔。

## 输入输出样例 #1

### 输入 #1

```
5
1 2 3 4 5
```

### 输出 #1

```
1 1 2 2 3
```

## 输入输出样例 #2

### 输入 #2

```
5
2 4 6 8 10
```

### 输出 #2

```
1 2 3 4 5
```

## 输入输出样例 #3

### 输入 #3

```
5
3 3 1 3 2
```

### 输出 #3

```
1 1 2 2 2
```

## 说明/提示

尺寸相同的两个背包不能互相嵌套，搜索到重复尺寸不会增加可用的不同尺寸。

## 样例解释

- 样例 1：尺寸 $1,2,3,4,5$ 全部出现后，可以选出尺寸 $1,3,5$，形成 $3$ 层嵌套。
- 样例 2：相邻出现尺寸相差 $2$，每个新尺寸都可以接在已有嵌套链外侧。
- 样例 3：重复尺寸 $3$ 不增加层数；尺寸 $1$ 与 $3$ 可以嵌套，但尺寸 $2$ 不能插入这条链。

## 数据规模和约定

::cute-table{tuack}
| 测试点 |  $n$ 范围 |
|:---:|:---:|
| 1--5 |  $1\le n\le 200$ |
| 6--10 |  $1\le n\le 1000$ | 
| 11--15 |  $1\le n\le 10000$ |
| 16--20 |  $1\le n\le 100000$ |

对于全部测试点，$1\le n\le 100000$，且 $1\le a_i\le 500000$。
